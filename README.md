## 维护公开记录

公开新闻和成果收录2021年至今的事项。

在 `site/assets/records.json` 编辑“成果与活动”的条目。每条使用唯一且稳定的 `id`，按内容选择一个类别。

| 类别 | 收录范围 |
| --- | --- |
| 教学（`teaching`） | 授课、教学成果、指导学生参加学科竞赛 |
| 科研（`research`） | 论文、项目、学术影响 |
| 社会服务（`service`） | 期刊工作、学术组织任职、对外讲座及交流 |
| 新闻报道与研究传播（`media`） | 面向公众的研究解读、双语传播与媒体报道 |

`role` 可填写第一作者、指导教师或受邀报告人等身份。作者顺序或具体分工已列于 `detail` 时可留空。团队成果应注明团队和个人各自的贡献。`sources` 附可核对的公开出处，采用能够核实相关事实的期刊原文、发布机构或主办单位的公开记录。每个来源须包含名称 `label` 和可访问的网址 `url`。没有公开链接的条目省略来源区，校内材料及确认过程留在非公开核查记录中。期刊论文、主办方公告、学校新闻等使用可公开访问的完整 `https://` 或 `http://` 网址，保留必要的查询参数和页码。页面显示名称与完整网址；需要另行核对的事项暂存于非公开核查记录。经本人明确授权用于展示的官方证书等站内附件放在 `site/assets/`。日期按来源实际支持的精度填写，`date_label` 标明出版、授奖、报告或主页收录等时间含义。未列年份的现任职务和课程可使用 `null` 日期，成果页支持按年份、类别和关键词筛选。

例如，网络谣言验证论文的中文原文刊于《图书情报知识》2025 年第 5 期。入选双语传播工程是另一条动态，2026 年 11 月 22 日仅为主页收录日期。2026 年全球前 2% 顶尖科学家动态则采用第九版榜单的发布日 2026 年 10 月 7 日；沈校亮入选的是统计 2025 年引用的年度科学影响力榜单。

## 更新页面与课程

首页已为生活影像预留发布位置。在收到获准公开的照片或短片后，将有内容的栏目加入首页标注位置，并补上图片说明或视频字幕。

新闻按日期倒序写入 `site/index.html` 和 `site/news.html`。每条新闻在日期下用 `news-date-label` 标明日期含义，例如“活动时间”“榜单发布”“获奖公示”或“证书日期”。同一条新闻在两个页面使用相同的标签。其他栏目编辑对应的 HTML。`site/facts.html` 由数据生成，请修改源记录后重新构建。课程入口为 `site/course-lab.html`。现有 V1.9.3 在线版为 `Information_Reception_Lab_V1_9_3.html`，离线教学包为 `Reception_Lab_V1_9_3_Student.zip`。升级实验室时一并更新两个文件及课程页链接，分别测试打开实验和下载解压。离线包包含可独立运行的完整实验页面。课程计算、样本和导出在本地工作，期刊和数据来源以完整网址列出，联网时可打开。课程数据集的样本行保留外部观察对象入口，供学生核对。

## 构建与发布

在仓库根目录运行以下命令，生成事实页、本地完整发布包 `site.zip`、`release-parts/` 下的 8 MiB 分片及记录各分片和整包 SHA-256 的 `release.json`。

```sh
python3 tools/build_release.py
```

将修改的源文件、生成的事实页、`release-parts/` 全部变更和清单一并提交到 `main`。`site.zip` 供本地校验，发布器按同一提交下载清单和分片，逐片核验长度与摘要，再校验重组 ZIP 的完整摘要。发布包上限为 64 MiB，单个公开文件上限为 12 MiB，解压总量上限为 128 MiB，最多 512 个文件。武汉服务器约每十分钟检查一次，解包并验证课程文件后切换站点。发布后从正式域名打开实际变更的页面，核对日期、来源和下载链接。
