## 维护公开记录

成果与活动中的每条公开记录可通过同一 ID 在新闻动态中定位。合并动态时可在保留的条目中使用 `data-news-alias` 标记原条目的定位 ID。按照可核对的时间归档，日期只有年份或月份时沿用该精度。日期未列的现任职务放在新闻动态的现任职务区。首页“现任职务”链接到个人简介中的现任职务列表。

在 `site/assets/records.json` 编辑“成果与活动”的条目。每条使用唯一且稳定的 `id`，按内容选择一个类别。

| 类别 | 收录范围 |
| --- | --- |
| 教学（`teaching`） | 授课、教学成果、教学专访、指导学生参加学科竞赛 |
| 科研（`research`） | 论文、项目、学术影响与研究传播 |
| 社会服务（`service`） | 期刊工作、学术组织任职、对外讲座及交流 |

`role` 可填写第一作者、指导教师或受邀报告人等身份。作者顺序或具体分工已列于 `detail` 时可留空。团队成果应注明团队和个人各自的贡献。`sources` 附可核对的公开出处，采用能够核实相关事实的期刊原文、发布机构或主办单位的公开记录。每个来源须包含名称 `label` 和可访问的网址 `url`。没有公开链接的条目省略来源区，校内材料及确认过程留在非公开核查记录中。期刊论文、主办方公告、学校新闻等使用可公开访问的完整 `https://` 或 `http://` 网址，保留必要的查询参数和页码。页面显示名称与完整网址；需要另行核对的事项暂存于非公开核查记录。经本人明确授权用于展示的官方证书等站内附件放在 `site/assets/`。同一奖项可以并列链接公开报道、组委会公告和获准公开的证书。日期按材料实际支持的精度填写，成果与活动的 `date_label` 中省略日期后的括号来源说明，具体出处列在条目下方。未列年份的现任职务和课程可使用 `null` 日期，成果页支持按年份、类别和关键词筛选。

例如，网络谣言验证论文的中文原文刊于《图书情报知识》2025 年第 5 期。入选双语传播工程是另一条动态，2026 年 11 月 22 日仅为主页收录日期。2026 年全球前 2% 顶尖科学家动态则采用第九版榜单的发布日 2026 年 10 月 7 日；沈校亮入选的是统计 2025 年引用的年度科学影响力榜单。

## 更新页面与课程

首页已为生活影像预留发布位置。在收到获准公开的照片或短片后，将有内容的栏目加入首页标注位置，并补上图片说明或视频字幕。

期刊论文动态的标题和正文首句写完整题名、刊名以及“录用”或“发表”。随后用一两句话介绍期刊的主办或出版单位、办刊领域和可核对的收录信息，附期刊简介或收录来源。录用动态使用录用日期，成果记录使用“期刊录用”类别，科研页同一编号的论文条目注明期刊、录用日期和“已录用”。发表动态使用可核对的发表日期。项目动态注明项目或子课题的全称。

同一篇论文在同一会议仅保留一条动态，合并录用、报告和相关入围消息。标题写完整题名、会议名以及可核实的论文类型或议程安排。正文交代会议日期、地点或线上形式、合著者和报告或录用情况。动态按会议日期归档，已有具体报告日时采用该日，日期精确到日。会议论文、海报和报告在科研页同一论文列表列出。会议以外的期刊发表或录用事件按实际日期各自进档。

新闻按日期倒序写入 `site/index.html` 和 `site/news.html`。每条新闻在日期下用 `news-date-label` 标注事项类型或日期含义。课题立项、主持、参与、开题和结题统一标“研究项目”，讲座、座谈、沙龙、会议和宣讲等统一标“活动交流”。论文发表、录用及基于论文的传播标“学术论文”，期刊任职、收录、指标、专刊与编辑工作标“期刊工作”。指导学生参加学科竞赛及相关指导教师奖统一标“竞赛指导”，师资研修及获得培训交流证书的教学研讨统一标“教学培训”。其他条目可按实际日期标“榜单发布”“获奖公示”或“证书日期”等。同一条新闻在两个页面使用相同的标签。其他栏目编辑对应的 HTML。`site/facts.html` 由数据生成，请修改源记录后重新构建。课程实验使用固定入口 `site/information-reception-lab.html`，旧版在线入口仍可跳转。升级时在固定路径替换在线实验，更新离线教学包及相关链接，测试打开实验和下载解压。首页、新闻动态与成果记录沿用 `teaching-reception-lab` 条目，更新日期、说明和必要的下载链接，移除该实验的上一条动态。标题和在线入口均省略版本号。离线包包含可独立运行的完整实验页面。课程计算、样本和导出在本地工作，期刊和数据来源以完整网址列出，联网时可打开。课程数据集的样本行保留外部观察对象入口，供学生核对。

## 构建与发布

在仓库根目录运行以下命令，生成事实页、本地完整发布包 `site.zip`、`release-parts/` 下的 8 MiB 分片及记录各分片和整包 SHA-256 的 `release.json`。

```sh
python3 tools/build_release.py
```

将修改的源文件、生成的事实页、`release-parts/` 全部变更和清单一并提交到 `main`。`site.zip` 供本地校验，发布器按同一提交下载清单和分片，逐片核验长度与摘要，再校验重组 ZIP 的完整摘要。发布包上限为 64 MiB，单个公开文件上限为 12 MiB，解压总量上限为 128 MiB，最多 512 个文件。武汉服务器约每十分钟检查一次，解包并验证课程文件后切换站点。发布后从正式域名打开实际变更的页面，核对日期、来源和下载链接。
